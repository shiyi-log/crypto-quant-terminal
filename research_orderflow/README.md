## 2. 判据（先冻结，不许中途改）

**核心问题：订单流失衡能否产生足够的方向性毛优势，扣掉成本后为正？**

| 项 | 冻结值 |
|---|---|
| **方向定义** | **动量**：失衡高 → 做多；失衡低 → 做空（下标实测为动量，见 4.2） |
| **信号构造** | 按时间桶聚合 `signed_volume / total_volume`；桶内主动买为正（`buyer_maker=False`） |
| **禁用** | 不得按「全样本分位」定阈值（前视）；阈值必须只用截至当桶的历史 |
| **成本口径** | maker 2 bp/边 · taker 5 bp/边（实测 config）· 滑点与资金费记 `unknown` |
| **通过条件** | 毛优势 > 往返成本，且在**至少两个独立时间段**成立 |
| **禁止** | 只报 IC 不报 bp —— **IC 显著不等于能赚钱**（本线第一轮就踩到这个） |

## 4. 第一轮结论（已定，可被新证据推翻）

### 4.1 信号是**真的**

**逐笔 1 秒级 IC = −0.21（t = −70.83）不是噪声。它稳定、显著、跨 BTC/ETH 一致。**

### 4.2 但方向是**均值回归**，不是追涨

**5m 层面：失衡越高，下一根收益越低（BTC 五分组完全单调）。**
**逐笔层面：短持有期（≤60s）表现为动量，300s 后转为反转。**
**→ 任何实现都必须先测清符号随持有期的变化，不能假设单调。**

### 4.3 量级**差两个数量级**

```
信号毛优势:  0.006 ~ 0.067 bp
往返成本:    4 bp（maker）~ 10 bp（taker）
→ 信号 = 成本的 0.15% ~ 1.7%
```

### 4.4 做市路径**同样堵死**

```
BTC 价差 = $0.10 / 81762 = 0.0122 bp   （100% 时间为 1 tick）
ETH 价差 = $0.01 / 2474  = 0.0404 bp   （99.9% 时间为 1 tick）
做市赚半价差: BTC 0.0061 bp · ETH 0.0202 bp
maker 手续费: 2 bp/边
→ 每成交一次净亏约 2 bp
```

### 4.5 根因是**费率档位**

**0.02%/0.05% 的零售档，比这条线路需要的费率高出 50~500 倍。**
**这不是策略问题、不是参数问题、不是数据问题 —— 是账户成本结构问题。**

## 5. 什么条件下结论会反转（唯一出口）

| 条件 | 现值 | 需要 |
|---|---|---|
| **maker 费率** | 2 bp/边 | **≤ 0.03 bp/边** |
| **或：做市返佣** | 无 | **≤ 0.03 bp/边（含返佣后）** |
| **或：信号强度** | 0.006~0.067 bp | 提高 **50~500 倍** |

**第一、二项意味着需要与交易所建立做市商关系（当前账户不具备）。**

**→ 因此本线路在**当前账户条件下**关闭。若将来获得做市返佣档位，可重启。**

## 用户定的方向

> 「长期观察**订单量突增**会不会造成价格暴涨或暴跌，寻找入场机会；

**这与我第一轮测的东西不同：**
| | 第一轮 | 第二轮（正确方向） |
|---|---|---|
| 自变量 | 买卖**失衡** `flow_imbal` | **订单量突增** `quote_volume / 基准` |
| 因变量 | 下一根收益 | 后 30 分 / 1 小时的收益**与幅度** |
| 目的 | 方向预测 | **找暴涨暴跌的入场机会** |

## 冻结的检测方法（无前视）

```
观测值 = extras.quote_volume（当根报价成交额）
基准   = 截至【前一根】的 288 根（1 天）滚动中位数
         ⚠️ 实现必须 shift(1) 后再 rolling —— 禁止用全样本分位
量比   = 当根 quote_volume / 基准
阈值分档 = 2x / 4x / 8x / 20x
```

| <1x | 144,987 | +0.002% | 0.183% |

**「突增后波动幅度变大」单调成立（0.18% → 0.57%）。方向偏正（延续），不是反转。**

### 严格检验

**ETH · 突增(≥20x) · 806 次 ≈ 322 次/年 · 判定 PASS**

```
分布:   5%分位 -1.865% · 95% +2.099% · 最差 -8.261% · 最好 +11.614%
```

**BTC · 突增(≥20x) · 817 次 ≈ 327 次/年 · 判定 FAIL**

```
后30分: +0.0441% · t=+1.34 · p=0.180 不显著 · 需费率 <0.0221%/边（正好卡在 maker 上）
稳定性: 前半 +0.0667% → 后半 +0.0260%   ← 递减
```

# 第三轮 · 反向问法（用户明确要的方向）

## 用户的问题

> 「重点观察，**价格暴涨或暴跌前后**有没有订单量和交易量突增的信号，研究他们的关系。」

**这是第二轮的反向：**
| | 第二轮 | **第三轮（用户真正要的）** |
|---|---|---|
| 问法 | 量突增 → 价格怎么走 | **价格暴涨暴跌 → 之前/之后有没有量突增** |
| 用途 | 找入场 | **找领先信号** |

## 统计陷阱（必须先讲）

**从暴涨往回看，成交量必然高 —— 因为大涨本身就是大量。**
所以「事件前平均量比高」**不能证明**它是领先信号。
**唯一有效的检验是条件概率：P(爆发 | 量比档) vs 无条件概率。**

## 检验一：量比剖面（事件前后）

**事件 = 未来 3 根（15 分钟）内 |收益| ≥ 1.5%**

| 相对事件根 | BTC 暴涨前量比 | ETH 暴涨前量比 |
|---|---|---|
| t−12 | 6.29 | 2.85 |
| t−3 | 4.60 | 3.78 |
| t−1 | 5.30 | 4.07 |
| **t+0（事件根）** | **6.29** | **4.90** |
| t+1 | — | 7.37 |
| **t+3** | **14.62** | **11.59** ← 峰值 |
| t+12 | 6.29 | 3.52 |

**结论：量在爆发【前】就开始抬升，但【峰值在爆发之后】。**
**所以量的最大部分不是领先信号，而是爆发的【结果】。**

## 检验二：条件概率（决定性）

**无条件概率**：BTC 0.21% · ETH 0.59%（任一根 15 分钟内 ±1.5%）

| 量比档 | BTC 根数 | BTC P(任一) | BTC 提升 | ETH P(任一) | ETH 提升 |
|---|---|---|---|---|---|
| <1x | 144,987 | 0.05% | 0.3x | 0.21% | 0.4x |
| 1~2x | 78,197 | 0.19% | 0.9x | 0.53% | 0.9x |
| 2~4x | 41,096 | 0.34% | 1.6x | 0.95% | 1.6x |
| 4~8x | 16,867 | 0.61% | 3.0x | 2.16% | 3.7x |
| 8~20x | 5,933 | 1.48% | 7.2x | 3.23% | 5.5x |
| **≥20x** | **818** | **4.28%** | **20.8x** | **7.93%** | **13.4x** |

**单调、干净、两币一致。这是本研究里【最强的统计关系】。**

## 但它预测的是【波动】，不是【方向】

```
BTC ≥20x:  P(涨) = 2.44%  ·  P(跌) = 1.83%   → 几乎相等
ETH ≥20x:  P(涨) = 4.21%  ·  P(跌) = 3.72%   → 几乎相等
```

**而且即使 ≥20x，也只有 4.28%/7.93% 会爆发 —— 91.6%/92% 的突增不会。**

## 检验三：与失衡组合能否给出方向（失败）

| 条件 | BTC n | BTC 均值 | BTC 胜率 | ETH n | ETH 均值 | ETH 胜率 |
|---|---|---|---|---|---|---|
| 量≥20x 且 失衡>+0.2 | 203 | **+0.0968%** | **47.8%** | 156 | **+0.1345%** | **46.8%** |
| 量≥20x 且 失衡<−0.2 | 196 | −0.0637% | 52.6% | 214 | +0.0018% | 56.1% |

**⚠️ 均值正、胜率却低于 50% —— 正收益来自极少数大赢家，多数交易是亏的。**
**这是厚尾效应，不是稳定优势。且样本仅 156~214 笔。**
**→ 失衡【不能】为突增提供可靠方向。**

## 第三轮结论

| 问题 | 答案 |
|---|---|
| 暴涨暴跌前后有没有量突增？ | ✅ **有，且关系很强**（提升 13~20 倍） |
| 量突增是否**领先**于价格爆发？ | ⚠️ **部分领先**（t−3 就抬升），**但峰值在爆发之后** |
| 能否用它**预测方向**？ | ❌ **不能** —— P(涨) ≈ P(跌) |
| 能否用它**预测波动**？ | ✅ **能，且很强** |
| 加失衡能否补上方向？ | ❌ **不能**（均值与胜率符号矛盾，厚尾驱动） |

**实用含义：量突增是「准备动作」信号（要动了、仓位要小心），不是「买卖」信号。**
