# 运行健康视图

此只读视图分别报告实时采集、来源文件同步、REST K 线归档、数据完整性和存储配置，不把同步完成解释为数据全部健康。接口不会修复数据、启动服务或改变门禁。

## 数据来源与边界

- 采集读取主采集器、TRX 侧车、现货采集器各自的本地状态，分别核验状态心跳、最近消息和最近落库；缺失状态不会显示为零错误。历史累计失败计数保留为指标，不单凭计数认定当前仍失败。
- 来源文件同步读取 `store_metadata.sync_state`，不用数据库总览的全表计数；扫描和导入完成不证明行情新鲜或完整。
- REST K 线归档读取认证进程内 `CandleArchiveWriter.status`，记录当前待处理行数和错误。该对象尚无最后成功提交时间，接口返回未知；不能用读取时间冒充成功提交时间。Market-live 独立进程内的归档器需要单独健康来源，不能以当前进程快照替代。
- 完整性检查读取独立报告状态；检查失败、过期、缺少 `ok` 或计数等关键字段均保持显式。
- 存储核验预期外盘挂载和 UUID、可写状态以及空间。未配置外盘标为迁移待完成；只读检查不会创建目标目录。路径辅助配置已经存在也不能证明全部服务已经完成迁移。

只返回固定公开错误码和允许的数值/布尔指标，不返回异常文本、连接信息、凭据、绝对路径或状态文件中的任意附加字段。

## 前端行为

运行健康卡片独立于策略运维快照刷新；加载失败保留上次成功快照并标明读取错误。所有组件状态、更新时间、最后成功时间和错误码分别显示。未知指标显示未知，真实的零保留为零。

测试使用临时状态文件、明确时间和卷探针，不连接生产数据库、不操作真实挂载或服务。实际接口、类型检查和构建验证由主代理集中执行。
