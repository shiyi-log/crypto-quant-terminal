# 风险金额精度与补充页面视觉验证

本小节修复交易台风险栏完整小数被拆成孤立尾数的问题，并补充纸面策略档案、
Demo 设置和个人身份页的只读浏览器覆盖。真实构建的 Vue 页面直接读取合成
API；不连接真实账户，不保存凭据、不修改密码，不发送交易或会话命令。

## 金额展示

风险栏保留后端返回的完整十进制字符串，不转换浮点、不舍入、不用省略号替代
尾数。权益列在桌面获得更多宽度，所有风险金额保持单行。超出窄列的金额仅在
自身区域横向滚动，页面文档宽度不增加。

净权益、当日净损益和峰值回撤可用 Tab 聚焦，焦点有清晰轮廓；左右方向键可
逐段查看完整数字。鼠标悬停也可查看原始金额。净权益下方说明长金额可横向
查看，未知值仍显示“未知”，不会补成零或通过。

## 浏览器回归与覆盖

新增 `e2e/precision-visual.spec.ts`，在 1920、1440、768、390 四种宽度读取
完整金额 `1000.1234567890123456789`。测试从真实文本 Range 计算行数，
验证只有一行且字号至少 20px；窄列实际使用键盘滚到最右端，核对仍保留完整
文本和文档宽度。恢复任意数字换行时，四个视口均真实失败，修复后通过。

另在 1440、390 两种宽度打开真实纸面策略档案、Demo 设置和个人身份页，
等待有效内容后截图。纸面策略使用明确的历史合成账户，保留“纸面”与资格
未知边界；其历史 100x 身份不作为新 10x 计划的准入证据。所有业务写请求、
遗漏 API、页面错误均由夹具记录并要求为空。

输出通过运行参数写入独立目录，避免覆盖已跟踪的浏览器证据：

```bash
PLAYWRIGHT_HTML_OUTPUT_DIR=/private/tmp/quant-precision-final-report \
pnpm --dir vben/apps/web-antd exec playwright test \
  --output=/private/tmp/quant-precision-final --reporter=list
```

2026-11-17 本机验证：新增 10 项通过；完整浏览器 96 项通过；增强键盘尾数
检查再次 4 项通过；生产构建 11/11 成功，应用类型检查通过。完整前端
Vitest 最终 144 文件、1161 项通过。

完整 Vitest 前两轮分别出现共享表单原生提交事件和 blur 校验的时序失败。
底层异步校验即使 debounce 为零仍经过定时器，原测试仅 `flushPromises`
会在校验完成前断言。两项改为受控定时器后先稳定复现失败，再显式完成真实
校验调度；原始字段不得从提交事件泄漏的断言保持完整。没有修改生产表单
实现，也没有增加任意等待时长。

## 目视结果与限制

实际查看桌面权益完整一行、手机键盘滚动后的末尾，以及三页两种宽度截图。
正文未见叠盖或文档横向溢出；手机设置和身份导航可读。1440 和更窄金额可能
需要局部滚动才能看到尾数，这是保留精度的展示行为。

这些截图覆盖默认分区及首个可见工作面，未穷尽内部滚动底部、每个标签页、
错误/过期/抽屉状态或真实服务流程。手机全局 Vben 工具栏与偏好悬钮仍按
既有壳层显示，本小节没有改造它们。测试和截图不证明来源真实性、风险准入、
Demo 验收或正式实盘资格。
