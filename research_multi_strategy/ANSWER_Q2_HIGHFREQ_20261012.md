# Q2 答案：秒级/高频交易在散户费率下有没有利润？

> 2026-10-12 · DSH · 目标第 62 轮 · **结论：没有。**（基于实盘数据实测，非推断）

## 一句话结论

**毛边际（0.19 ~ 1.40 bp）在最便宜的成本（maker 4 bp 往返）面前全程不及格。**
从 10 秒到 4 小时，最佳情形也只有成本的 **35%**；秒级（1~60 秒）只有 **5~17%**。

## 2. 收益侧（毛边际实测）

**方法**：用 10Hz 订单簿构造订单流失衡信号 `OBI = (Σbid_vol[1..5] − Σask_vol[1..5]) / (Σbid+Σask)`；
`|OBI| ≥ 阈值` 时按 OBI 方向入场，持有 H 后按中间价出场，**未扣任何成本**。

```
样本: 209 万个快照 · 68.8 小时 · BTC/USDT:USDT（2026-10-08 22:23 → 10-11 19:01）

  持有期   OBI≥0.9   OBI≥0.7   OBI≥0.5  │ maker成本  taker成本
  10s      0.539     0.391     0.297    │   4.0       10.0
  30s      0.635     0.486     0.376    │   4.0       10.0
  1m       0.669     0.512     0.399    │   4.0       10.0
  5m       0.700     0.549     0.438    │   4.0       10.0
  15m      0.749     0.596     0.405    │   4.0       10.0
  1h       1.401     0.564     0.188    │   4.0       10.0
  4h       1.208     0.490     0.517    │   4.0       10.0

  单位: bp/笔 · 全部【未扣成本】
```

## 3. 判读

```
最佳情形: 1.401 bp（1h 持有 · OBI≥0.9）
成本底线: 4.0 bp（maker，最便宜）
→ 最佳情形 = 成本的 35%  → 【必负】

秒级区间(1~60s): 0.187 ~ 0.669 bp = 成本的 4.7% ~ 16.7%
→ 秒级是最差的区间，不是最好的
```

**⚠️ 曲线形态**：毛边际从 10s 的 0.54 bp 缓慢升到 1h 的 1.40 bp 后**平台化**，
**不会继续上升去追 4 bp 的成本**。这说明「换更长的持有期」不能救这条信号族。

## 5. ⚠️ 局限（必须随结论一起引用）

1. **样本仅 2.86 天 / 68.8 小时** —— 单一市场状态
2. **单一资产（BTC）** —— ETH 类似但未逐项测
3. **窗口内未包含闪崩** → 尾部滑点（真实崩盘时）**未被测量**
4. **只测了一族信号（OBI）** —— 其他信号族可能捕获更多；但对「秒级」而言，
   OBI 是文献里最强的短周期特征之一（arXiv 2602.00776 指出订单簿特征跨资产稳定）
5. **未扣资金费**（若持仓跨资金费结算点）
6. 这是**可实现性检查**（信号是否可达），**不是策略选择**

## 6. 结论的效力

- **对「秒级/高频在散户费率下能否盈利」**：✅ **可以下否定结论**（实测最佳情形只有成本 35%）
- **对「是否有任何策略能盈利」**：❌ **不能下结论** —— 本测只覆盖订单流失衡一族
- **对 Demo 的必要性**：⚠️ 本结论**不需要 Demo** 即可成立（成本两项均已实测/已知）
  → Demo 的价值因此集中在 **Q1 费率结构** 与 **Q3 限价单未成交率**
