# 版本记录

## 0.2.2 — 2026-11-17

本版本准备交付后续安全组件、研究证据和全站工作区改造。P1 生产证据链、
专属 writer、P2 真实研究执行与 P4 自然验收继续实施；代码发布不授予策略、
增资、异常恢复或真实交易批准。

- 账户级不可变 EntryDecision、Decimal 风险定仓与事务预占；跨策略共享
  1%/2%/50% 和两币预算，未知提交、部分成交及撤单回执保留占用。
- 原生条件订单接口、追加式条件账本及保护协调：单次 claim、未知只查、
  新保护确认后才撤旧保护、冻结 R/ATR、费用覆盖与单向保护移动。
- 全类型资金分窗、账户/订单原子请求证据、完整往返成本归属和持久完成事件；
  五字段运行身份与五 hash 冻结清单，保留部分失败，完整清单可离线重放。
- 归档 Provider 桥、安全运行时和只读验收服务组件；缺少内部可信语义证据、
  精确午夜或真实原生保护资格时保持阻断。
- 全局冻结 SQL 基线、显式迁移与只读结构检查；启动/重启预检失败保留现有
  进程和运行意图。0003–0006 Demo 迁移覆盖条件单、风险预占、证据及研究。
- 不可变研究版本/实验族/尝试/产物/裁定注册表；留出消费与首次票据在同一
  事务提交，重启和精确重试不重复出票，失败不重置。
- 实际本地文件字节 SHA、严格 JSONL 与显式 available_ms 质量核验，生成
  内容寻址产物和可复现快照；哈希不提升来源信任，未知来源保持不可评估。
- 深海蓝应用壳及因子、订单流/价格、策略、实验任务、数据、运维、账户设置、
  认证和系统工作区；保留旧 API 的真实能力、精确金额和会话切换边界。
- 全量前端测试、类型检查、生产构建与四视口真实 Vue Playwright 进入 CI；
  后端 PostgreSQL、冻结身份、显式源码清单与精确 SHA 发布身份门禁同步。
- 修复 BufferedReader 预读影响 pg_restore 子进程的真实故障；实际隔离合成
  恢复覆盖 47 表、34 行，八张研究表均非空，已消费留出及不可变约束保持。

发布前仍须当前交付提交的 CI、唯一 v0.2.2 标签 CD、Release 和独立下载包
SHA/build.json 核验。测试计数和精确链接以开发台账中的最终回执为准。
研究统计/成交模型、来源认证、专属 writer、生产 selector/API 组合根及
Demo/实盘自然运行尚未完成，不能把这些组件或旧纸面收益当作正式验收。

## 0.2.1 — 2026-11-16

本版本交付全栈重构的首批风险、验收和只读页面能力。P0–P4 仍在执行；
代码发布不构成策略上线、资金升级或真实交易授权。

- 风险事件显式 SQL 迁移，checksum 兼容检查、追加序号、冲突事务回滚及
  数据库禁止修改、删除、截断风险历史。
- 北京日界、日初净权益、外部资金流调整、日损 20/30/40/严格超过 50、
  阶段回撤和消费式三连亏政策；坏快照和账本错误保留退出保护。
- 核验实际与冻结杠杆不超过 10、逐仓、单向和自动追加保证金关闭；
  原生条件保护未验证时正式验收保持阻断。
- 净权益/完整分页流水对账 reducer；固定 30 天身份、完整往返、首尾账户
  快照和硬失败优先的验收裁定器。生产读取追加式人工批准链。
- 新交易台和验收页，默认进入交易台；会话切换丢弃旧响应，失败保留旧值
  并明确标记，未知资金费与原生保护不显示为通过。
- CI 增加量化/API/认证前端测试和新 Demo 模块检查；CD 验证精确提交 CI、
  单一版本标签、归档 SHA-256 和 build.json，Release 独立写权限。

本机最后完整验证：后端 2345 项通过、8 项可选环境跳过、3133 子测试通过；
风险/控制器定向 324 项与321子测试通过；风险存储45项与20子测试通过；
Demo集成54项与6子测试通过；前端141项、类型检查、11/11生产构建通过。
四种视口的合成夹具已检查，无整页横向溢出。发布前以待交付 SHA 的远端 CI
结果为最终证据。发布身份及工作流契约最新定向回归 13 项通过，依赖锁检查通过。
