## 策略研究

`/quant/research` 重写为候选方向账本、七类历史研究和所选方向证据检查区。深蓝工作面、紧凑行表、局部横向表格和窄屏上下排列取代原同款卡片堆叠。颜色遵循计划的 `#0C1B2A`、`#132B3E`、`#29485C`、`#E5EDF4`、`#A2B8C9`、`#69B4E4`；字体声明使用 IBM Plex Sans 和思源黑体回退，未声称已安装自托管字体资产。

保留 `/locals/research`、`/locals/research_status` 的真实只读数据和每分钟刷新：

| 原功能 | 新位置 | 口径 |
| --- | --- | --- |
| 研究方向与推荐/证伪 | 研究方向账本、所选方向检查区 | 明确标历史推荐/辅助/证伪，不能视为批准 |

`candidate=<精确研究名称>` 和 `section=<板块键>` 保留在查询参数中。指定候选不存在时显示缺记录；空或重复 candidate 明确身份无效，不能自动打开其它研究。纸面档案、实验任务与历史模型入口使用 RouterLink，兼容生产 hash 路由。历史模型入口尚不承诺 identifier 精确产物定位，由对应实验详情子节接线。

严格解析真实空列表与损坏合同；重复或缺失身份拒绝替换既有快照。失败保留上次成功来源并展示告警和生成时间。每次刷新递增请求身份，卸载取消发布；现有 API 不支持 AbortSignal，浏览器传输本身不会被页面的 AbortController 中止，迟到结果由 generation 丢弃。无时区历史空格时间按北京时间解释，无法验证的时间不推断新鲜。

未知冻结策略/代码/数据指纹、完整成本、压力评估、样本外下界、一次性留出、原生保护和人工批准均保持未取得，研究页面不设置本地通过布尔值。

## 纸面账户档案

`/quant/strategy-lab` 和 `/quant/strategy-focus` 保留独立纸面账户语义，以策略候选账本和所选账户的定义、时间、成本、执行及档案为主结构。账户组、风险 R 档、止损 k 档及订单簿对照/过滤实验分别筛选；重点策略路径继续固定 canonical s03/s05 范围。

原持仓、订单、完整交易、净值曲线、规则、事件、原始记录及订单簿决策详情仍可读取，策略与实验臂身份不合并。历史高杠杆和旧成本模型是研究档案，不成为本轮逐仓、最高10倍政策的执行许可。手续费按来源模型展示；资金费和滑点未知时不声明完整净收益。冻结 hash 仅描述已有来源，不等于人工批准。归档账户清单受旧接口枚举范围限制，当前无记录不证明所有历史档案不存在。

数据从同一认证只读端点 `/locals/strategy-lab` 直接读取原始合同，避免便利 wrapper 把损坏的数组改为空。详情按精确 strategy_id 查询；跨账户记录拒绝。刷新失败保留同一账户的已有成功事实，切换账户立即隐藏旧详情，通过取消信号和请求身份阻止迟到结果覆盖新选择。页面不自动发送研究写命令或交易指令。

账户原始合同同时校验文本、布尔值、十进制数值、全局及账户执行口径、研究分组身份、预热计数和嵌套决策信号。损坏数据拒绝替换已有快照；旧记录冗余 strategy_id 缺失或 null 时仅从已经核实的账户范围补注，显式跨账户身份仍拒绝。账户详情只展示端点最近 100 条记录，不能称为全生命周期数量。
