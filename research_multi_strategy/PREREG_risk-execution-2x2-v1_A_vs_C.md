# 预注册协议 · risk-execution-2x2-v1 · 100× stop-timing A/C 前向对照

> 起草：Codex 备用3号（2026-10-13 20:4x）· 采纳并归档：DSH
> ⚠️ 本协议必须在**达到预注册样本前不得修改**；任何修改须记录版本与理由。

## 1. 研究问题

在同一策略族、同一 **100× 杠杆**、相同信号/手续费/仓位规则下，
把 `close_confirmed` 止损改为 `intrabar` OHLC 止损，**是否降低强平率**？

只比较 **`A_L100_close`** 与 **`C_L100_intrabar`**。
`B_L30_close` / `D_L30_intrabar`（30×）**不作为 stop-timing 主判据**
（实测两臂均 0 强平 ⇒ 存在天花板效应）。

## 2. 主终点（实验开始前固定）

```
liquidation rate = liquidation trade_closed 数 / position_opened 数
```

分母只纳入同时满足：
1. 同一新账户身份
2. `position_opened` 有 `entry` / `liquidation` / `stop` 字段
3. 对应唯一 `trade_closed`

**不按净 P&L 或止损率替换主终点。**

## 3. 主要比较

- 六族内按 `strategy family` **分层**的 A vs C
- crude rate 仅作描述；推断使用**预先指定的 CMH/分层精确方法**或固定效应 logistic，`family` 为 strata
- **禁止跨杠杆混合**
- ⚠️ 若 `s06` / `s12` 数据缺失 ⇒ 标记为**未完成**，**不得用四族结果宣称六族结论**

## 4. 次要终点（顺序预注册）

1. `stop_loss_intrabar` / `stop_loss_close_confirmed` rate
2. liquidation **conditional on** `stop_distance >= liquidation_distance`
3. net P&L/trade · gross P&L/trade · fees/trade
4. gap-through-stop rate
5. max drawdown

**次要终点只作估计和区间，不反向替代主终点。**

## 5. 方向与阈值

- 主要假设：C 的 liquidation rate **<** A
- **双侧 α=.05** 作为主检验；若要把「稳健」定义为 α=.01，必须在开跑前写明
- 同时报告：风险差 · 风险比 · odds ratio · 95% CI · 精确 p
- **不因 p 未达阈值而改换终点**

## 6. 样本与停止规则

| 项 | 值 |
|---|---|
| 分配 | 每族 A/C 尽量 1:1 |
| 合并主分析最低 | **74/臂** |
| 理想（每族可判断） | **63/臂/族** |
| 六族全做总量 | **756–888 笔** |

- **达到预注册样本前不看显著性停止**
- 仅允许操作性停止：无安全数据 · 执行身份/hash 不一致 · 重复 `trade_id` · 数据完整性失败
- 任一臂强平率或超限率异常升高 ⇒ 只触发**人工风险闸门/暂停新开仓**，**不得改终点**

## 7. 数据与排除

- **只用实验启动后的前向 paper 事件，禁止回填历史**
- A/C 账户并行运行、同一时段、同一市场数据源
- 按 `family` / `leverage` / `execution mode` 固定分层
- **先定义可审计排除规则**，排除项计数并报告，**不得事后按结果排除**
- 账户必须是**新身份**，`rule_hash` 与 `execution_hash` 可区分，**旧账户不原地修改**

## 8. 多重性与异质性

- 主终点只有一个
- 六族分别结果属**探索性**，报告未校正 + Holm/Bonferroni 校正
- 先检验 `family-by-arm` 异质性；若异质性明显，**不报告单一 pooled 因果结论**，只报告分族估计

## 9. 审计字段

`strategy_id` · `variant_of` · `arm_id` · `rule_hash` · `execution_hash` · `leverage` ·
`stop_execution_mode` · `entry_price` · `stop_level` · `liquidation_price` ·
`opened/closed` 时间 · `exit_reason` · `gross/net P&L` · `fees` · `data_fingerprint`

**不得标注盈利/通过/可用；结果只提交人工闸门评审。**

```

```

## 3. 名义口径（采纳备用2号）

- **主 estimand**：`notional_policy="frozen_signal"`
