⇒ 毛优势连成本都没覆盖。按仓库自己的纪律（「毛优势 > 往返成本」），当前**没有任何一项通过第一层筛选**。

⇒ 这是**一次市场单向行情**，不是 6 个独立观测。15m 上所有实现正收益的账户都由这同一段行情驱动。

## 三、核查中发现的三个真问题（比挑策略更值得先修）

### 3.1 风险上限没有被兑现（最严重）

按 `max_loss_per_trade_usdt`（R 档）核对每笔实际亏损：

| exit_reason | 笔数 | 超过 R 上限 | 占比 |
|---|---:|---:|---:|
| `stop_loss_close_confirmed` | 168 | **97** | **57.7%** |
| `liquidation` | 18 | **12** | **66.7%** |
| 其余 9 类离场 | **297** | 0 | 0% |
| 合计 | 483 | 109 | 22.6% |

⇒ 仓位公式本身是对的（非止损类离场**零突破**），**突破 100% 来自「收盘确认止损 + 次根开盘成交」的滑价**。
文档实测：实际逆行是设计止损距离的 **1.7 倍**。
⇒ **后果：R50/R200/R1000 三档不是硬约束，「按风险预算定仓」的整个因子设计失真。**

### 3.2 因子矩阵在高 R 档退化为重复

15m 上 30% 名义预算封顶（名义 150,000，保证金 1,500）。实测 `s01` 的 R1000 档：

```
k=1.0 / k=1.5 / k=2.5  →  名义完全相同（150,000）→ 交易完全相同（净 −511.33）
```

⇒ **k 因子在 R1000 档被预算咬合吃掉**，这些账户是纯重复，虚增名义样本。

### 3.3 有效样本被三层高估

```
669 笔记录  →  78 个独立信号（÷8.6）
            →  17 个小时块（同一小时内的信号高度相关）
            →  2 个日历日（≈2 次市场情形）
```

且 29 个策略共用 BTC/ETH 同一 `execution_universe`，方向互相抵消。
⇒ **「29 个策略」的有效独立实验数接近 1~2。**

## 四、值得深挖的方向（按证据强度排序）

### A. 执行与成本口径 —— 地基，应该最先做

- **为什么**：上面所有数字（毛 −14bp / 费 4bp）都建立在**未经成交验证的 maker 费率**上。实测：taker 0.0400%/边**有真实成交回报**；maker 0.0200%/边**只有账户报价**，post-only 单在 TTL=3s 下 **4/4 全部未成交**；端到端延迟中位 **2,250 ms**。
- **内部张力**：`strategy_simulation.py` 的 `fill_model = next_closed_bar_open_proxy`（下一根开盘成交 = **市价/taker 语义**）却按 **maker 费**扣钱 → 每笔系统性乐观约 **4 bp**。
- **外部对账**：独立分析称 Binance 两腿 delta 中性往返 taker 成本 0.40%，比项目 maker 口径高 5 倍；差异全在 maker vs taker。
- **具体动作**：① TTL 提到 8s 重跑一轮验证 maker 真实成交率与逆向选择；② 用 taker 费率横切重跑因子实验，统计有多少配置从正转负；③ Demo 侧补测真实滑点。
- **成本**：低。**收益**：决定其他所有方向是否成立。

### B. 反转族（s05 / s08 / s17）—— 唯一毛优势为正的内部线索

- **内部证据**：100× 臂毛优势排序，只有 s05(+36bp)、s08(+4.8bp)、s07(+4.2bp) 为正。
  离场原因分解（100× 臂，名义 bp）：

  | exit_reason | 笔数 | 毛 bp | 净 bp |
  |---|---:|---:|---:|
  | `mean_reversion_complete` | 37 | **+50.9** | +47.0 |
  | `take_profit_close_confirmed` | 10 | +22.5 | +18.5 |
  | `utc_day_end` | 40 | +19.8 | +15.8 |
  | `holding_period_elapsed` | 51 | +15.3 | +11.3 |
  | `orderflow_direction_reversed` | 81 | +6.9 | +2.9 |
  | `opposite_range_breakout` | 92 | −16.0 | −20.0 |
  | `stop_loss_close_confirmed` | 170 | **−36.7** | −40.7 |
  | `liquidation` | 26 | **−100.0** | −104.0 |

  ⚠️ **内生性警告**：离场原因是策略自己的规则触发的，不是独立证据
  （均值回归策略在**奏效时**才走 `mean_reversion_complete`）。它只说明「反转类离场 > 趋势类离场」，
  不能单独用来证明反转族有边际。
- **独立佐证**：项目自己的订单流失衡研究 IC = **−0.21**（t=−70.8，符号为负）→ 5m/分钟级**支持反转、反对延续**；突发量能研究结论是「量突增预测波动、不预测方向」。
- **⚠️ 必须并列的反证**：外部 JRFM 2026 论文用 **300 组合搜索 + Hansen SPA 检验**否证了日间/隔夜 session 族（s16/s17 同族），且 BTC 规则时序留出失败。
- **诚实的判定**：这是目前**唯一值得继续攒样本的机制方向**，但 n=6~17 且集中在一段行情，**不构成任何结论**。
- **具体动作**：不做单策略挑选（PREREGISTRATION §2c 已禁止），改用**族级合并 + 聚类稳健标准误**（§10）做事前固定检验；同时把有效样本问题（见第六节）解决。

### C. 市场中性配对 —— 外部证据最强、项目覆盖最少

- **外部**：协整选对 + copula 信号，10 个 Binance 永续 · 26,257 小时，**最大回撤 < 20%**（远好于趋势族 38~64%），基线成本 **0.08% 往返**（= 项目 maker 口径，且中性腿可挂限价单，**成本假设比趋势突破更站得住**）。这是外部证据里风险收益结构最好的一族。
- **项目现状**：只有 `s04`（单一 BTC-ETH 对，15m），100× 臂 **4 个唯一信号**，gross −7.7bp；`s32_cointegration_spread_1h` 仍是**未实现的候选提案**。
- **数据可行**：`quant.candles` futures 1h 有 **57 币 / 224 万行**，足够做协整选对。
- **为什么值得**：**成本模型可辩护 + 外部正面证据 + 项目几乎空白**，三者同时成立的方向仅此一个。

### D. Quattro 型 Donchian（4H + EMA200 过滤 + 金字塔 + 灾难止损）

- **外部**：独立 walk-forward + 已实盘；+1,107% / −37.5% DD / 94 笔 / 26.6% 胜率。
- **与项目已否证的 1d 趋势族**不冲突：被推翻的是「1d · 多币 · 无 regime 过滤 · 无金字塔」，Quattro 是**不同的条件规则**（Codex 在 s07 上已确立这一判别标准）。
- **⚠️ 保留**：11/94 笔（12%）贡献大部分 P&L，自述也暴露集中度 → 与前向样本需求冲突。
- **数据可行**：futures 4h 92,275 行 / 20 币；1d 476,582 行 / 167 币。
- **动作**：登记为**前向研究假设**规格，不因外部 +83% APY 就当作已验证。

### E. 清算级联（s21 / s35）—— 条件性，取决于数据

- **现有能力**：`s21_liquidation_cascade_fade` 已实现；DB 有 `orderflow_surge_events`（682 行）、`orderbooks`（BTC/ETH 各 ~260 万行）、`ticks`（357 万行）。
- **⚠️ 数据不足**：`open_interest` 仅 **1,000 行 / 2 币 / 2 天**；orderbooks 只有 **3 币、3 天**；清算事件流没有独立覆盖。
- **旁证**：本项目 100× 账户已实测 **26 笔强平**（每笔毛 −100 bp，即保证金全损）→ 机制在 100× 下**真实且频繁**。
- **判定**：**先补数据再接策略**；在当前数据上不可前向验证。

### F. 现有实盘 `TrendFollowing` —— **保留运行，但不值得加大研究投入**

- **保留的理由（唯一正面点）**：它是本项目**唯一通过显著性检验**的方向
  （7 年全样本 Sharpe **1.14 / t=3.03**，正偏，2022 年 −1.6% vs 买入持有 −70%+）。
  运行成本近乎为零（dry-run），没有理由关掉。
- **不加投入的理由**：
  1. **前向记录里 0 次策略自平仓**（11/11 全是外部 `force_exit`）→ 出场逻辑从未被前向验证；
  2. 有效独立结果事件 **≈2**（2.7 天 / 2 次干预）→ 统计功效为零；
  3. 「实盘 15.6%」是**误标的回测数**；同期真实干跑是 **−0.38%**；
  4. 全样本显著但**在衰减**：2023-2026 Sharpe 0.60(t=1.15) → 2025-2026 **0.23(t=0.30)**；
  5. 验证与部署**仍不是同一策略**（残差 70% Calmar 偏差 > 自定 20% 容差）。
- **动作**（低成本、高价值）：
  ① 修复验证↔部署一致性至 20% 容差内；
  ② 建立**无强平、无重建**的连续前向窗口，目标是 **≥30~50 笔策略自平仓**（约需 12 个月）；
  ③ 在该窗口达标前，**不接受任何基于这条线的年化主张**；
  ④ 解释当前库 id 缺 9、14 与旧库 10 个持仓消失的原因。

## 六之二、不扩币约束下的方案（2026-10-12 追加）

### 6b.1 先把约束的算术摆出来

**固定 BTC/ETH 后，能提高有效样本的维度只剩三个**：频率、方差、成本。三者都不是自由变量：

```
实测 BTC-ETH 收益相关性：15m ρ=0.8176（n=97,410）· 1d ρ=0.8245（n=5,017）
  → 2 币的有效独立资产数 ≈ 2/(1+0.82) ≈ 1.1，不是 2

固定币池 ⇒ 唯一能涨样本的是【频率】
频率↑ ⇒ 每笔毛优势被成本吃掉得更狠
⇒ 【成本成为唯一瓶颈】，而成本由 maker/taker 决定
```

### 6b.2 实测三条不动币池的杠杆

**杠杆一：降方差 —— BTC-ETH 配对残差（实测）**

```
BTC 15m  σ = 25.44 bp
ETH 15m  σ = 35.02 bp
β(ETH~BTC) = 1.126
残差 σ   = 20.16 bp     残差/ETH = 0.576
⇒ 相对 ETH 单边，所需样本 ÷ 3.02
⇒ 相对 BTC 单边，所需样本 ÷ 1.59
（N ∝ σ²，故 σ×0.576 ⇒ N×0.33）
```

**杠杆二：成本口径 —— 中性腿可挂限价单**

单边突破必须吃价（next-open = taker 语义，往返 **8 bp**）；
配对/中性策略两腿都可以挂限价，**maker 往返 4 bp** 才站得住。
这正是外部学术文献给配对策略用 0.08% 往返成本的原因。

**杠杆三：频率 —— 只能是 15m**

按 PREREGISTRATION §2b 实测触发率（15m · 2 币 ≈ 456~1,974 信号/年）：

| 路线 | 所需 N（检出 9 bp） | 达到时间 |
|---|---:|---|
| 单边 · σ=47.5 bp | 219 | 4~25 周 |
| **配对 · σ=47.5×0.576** | **73** | **2~8 周** |

（所需 N 用 N≈(2.8/(δ/σ))²，功效 80%、双侧 α=0.05；σ 取 100× 臂反转族实测值）

### 6b.3 结论：把 BTC/ETH 的资源集中到「相对价值 / 配对族」

**理由三条同时成立**（这是不扩币时唯一三条都满足的方向）：

1. **σ 更低**：实测残差 σ = 0.576 × ETH 单边 → 样本需求 ÷3
2. **成本可辩护**：中性腿挂限价，maker 4 bp 才成立；单边突破在 15m 上已被证明是成本墙
3. **与已证伪的「横截面动量」不同**：那是跨币排序（已被引擎前视缺陷连累撤回）；
   这里是**同一对币的相对价值**，机制和样本量问题都不同

**项目已有基础（不需要新建币池）**：

| 已有 | 状态 |
|---|---|
| `s04_btc_eth_pairs` | 已实现，15m，100× 臂实测 **4 个唯一信号 / 1.3 天**（频率很高，但样本太短不可外推） |
| `s10_lead_lag_btc_eth` | 已实现（BTC→ETH 信息传导） |
| `s30_dual_asset_confirmation` | 已建户，0 成交 |
| `s32_cointegration_spread_1h` | **候选提案，未实现** |
| `s36_correlation_regime_1h` | **候选提案，未实现** |

**具体动作**：

1. 先落 `s32`（协整价差 + ADF/KSS 选对参数）与 `s36`（相关性区制），**同币池、只加机制变体**
2. 把 `s04`/`s32`/`s36`/`s10` 定义成**一个事前固定的「相对价值族」**，走 PREREGISTRATION §10 的族级裁定（合并成交 + 聚类稳健 SE）
3. 全族统一用 **maker 4 bp** 成本口径（中性腿挂限价），并单独报告 taker 8 bp 敏感性
4. 裁定目标：族级有效样本 ≥73（σ 按配对口径），即 **2~8 周**内可出第一次结论

### 6b.5 ⚠️ 诚实的边界

