# 量化工作区应用壳

本小节记录重构计划 3.1、3.2 与 P3 的前端现状。应用使用 Vue Router；默认首页和旧量化兼容入口当前展示免认证的本地演示预览。预览不挂载账户工作区，不接入真实认证、业务服务或交易 writer，也不授予策略或资金阶段批准。

## 当前访问契约（2026-11-22）

- `/` 与登录默认首页进入 `/quant/demo-preview`。预览由交易台、研究、验收与运维三类固定样本组成，页面交互只改变本地视图状态。
- `/quant/trade-desk`、`acceptance`、`factors`、`experiments`、`data-quality`、`operations`、`orderflow`、`price-spikes`、`research`、`strategy-lab`、`binance-demo` 和 `security` 作为免认证静态别名进入对应演示子工作区。路由会保留原查询参数，并附加 `preview` 与 `workspace` 以选择样本页面。
- 兼容 URL 中的 `run_id`、`identifier` 等只用于保留浏览地址身份，预览不会读取对应业务数据。未列出的旧量化详情路径不再由量化动态路由承载，继续进入 404。
- 演示页不访问账户、认证 API、业务 API、writer、Binance 或生产数据库。页面上的金额、进度、审批和状态均为合成样本，不能作为 Demo 验收、真实交易事实或实盘准入证据。
- 旧量化页面组件源码、旧量化路由模块和共享旧页头已从前端源码移除；兼容入口只保留本文件列出的 core 静态演示别名。未来若恢复真实页面，必须作为独立工作重新验收其数据来源和安全边界。

下文的工作区壳布局说明记录此前实现与设计背景；若其中的旧路由可达性描述与本节不同，以本节列出的当前路由契约为准。

## 设计取舍

采用计划固定的深海蓝 `#0C1B2A`、工作面 `#132B3E`、分隔线 `#29485C`、主文字 `#E5EDF4`、次文字 `#A2B8C9` 与交互蓝 `#69B4E4`。字体使用本机 IBM Plex Sans、思源黑体或 Noto Sans SC，缺少字体时回落系统 sans-serif；不额外请求网络字体。壳级 token 同时作用于原侧栏、顶栏与工作面。

布局以紧凑的环境/身份栏承载账户边界，第二行承载八个工作区。桌面导航可换行；900 像素以下使用按钮展开两列导航，关闭时链接不参与 Tab。Escape 关闭后回到展开按钮，路由改变后关闭菜单。环境摘要独立 `role=status`，导航不进入 live region。工作区栏使用相对正文滚动容器的 `sticky top:0`；主体随内容增高而不压缩，避免滚动到底部时 sticky 越过父边界消失。浏览器验收在正文中段和最大滚动位置均核对环境栏仍在视口。

此前应用壳曾为旧引擎页面保留交易控制插槽；当前本地演示入口不挂载旧 BotControls，因此不会启动其 show_config/count 轮询或 WebSocket 订阅。

## 设计期环境分类

- trade-desk、acceptance、binance-demo：此前设计中的 Binance Demo 分类；当前兼容入口只显示固定本地演示样本，不读取账户事实。
- strategy-lab、strategy-focus：此前设计中的纸面研究分类；当前入口统一进入研究固定样本，不连接模拟账户。
- 旧引擎白名单：此前设计中的旧交易引擎分类；当前预览不会挂载旧控制组件或读取其运行配置。
- 其它已知研究、数据和证据页面：此前设计中的历史研究与证据分类；当前对应别名只显示本地样本。
- security：此前设计中的身份与安全分类；当前 `/quant/security` 进入治理固定样本，不挂载交易命令。

## 此前导航设计

八个导航入口均指向当前已注册路由：交易台 trade-desk、因子实验室 factors、订单流与价格 orderflow、策略研究 research、实验任务 experiments、验收与上线 acceptance、数据中心 data-quality、运维与证据 operations。独立因子工作区展示已有监控事实与证据缺口，不证明 factor_versions、研究门槛或最终留出服务已接通。历史入口继续保留原始查询身份。

原侧栏和历史路由的描述属于此前设计背景；当前实现以文档顶部“当前访问契约”为准。打开未列入兼容别名的 `strategy-focus`、`detail` 等深链会进入 404，已列入别名的查询参数只保留在地址中，不触发业务读取。

原 UserDropdown、退出登录、登录失效对话框、锁屏和水印逻辑保留。新壳不添加账户 API、后台轮询、交易写操作或新端口。

## 此前壳组件验证

组件测试使用真实 Vue DOM 挂载和内存路由，覆盖环境分类、活动导航、可到达链接、移动展开/关闭/焦点、保留精确深链、未知页与非量化页。实际 BasicLayout 测试在外部轮询边界替换 BotControls，验证 Demo/验收/运维从未挂载轮询，以及旧引擎切入 Demo 时卸载。原壳行为已实际复现失败，替换后测试通过。

浏览器验收须在生产构建后检查 1920、1440、768、390 宽度、正文滚动时的 sticky 栏、侧栏/主题、键盘焦点和无文档级横向溢出。组件测试不替代上述视觉证据，也不证明账户安全、原生保护或 30 天验收通过。
