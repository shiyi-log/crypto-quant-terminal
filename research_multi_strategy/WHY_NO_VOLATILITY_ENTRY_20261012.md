扣掉 4bp 成本后为负。瓶颈不在信号数量，而在方向性边际必须大于成本。**

## 第 3 步：我一度归因于「止损砍掉了好仓位」—— **被数据否证**

假设：止损（收盘确认+次根开盘出场，有滑价）把本可盈利的仓位砍了。

检验：取 176 笔止损单的真实入场价，看「若持有到今日收盘」的结果：

```
实际止损结果:        均值 −321.52 USDT/笔 · 合计 −56,587 USDT
若持有到今日收盘:     均值 −43.8 bp · 合计 −7,706 bp
其中【持有到期为正】:  60 / 176 = 【34%】
```

⇒ **只有 34% 会转为正；66% 即使不止损也亏。**
⇒ **止损不是主因；入场方向本身错误。**（我先前两次把主因判给止损，此处更正。）

**附带的真实缺陷（次要但确实存在）**：止损滑价
```
s02 short: entry 83508.0 → exit 83723.1 ⇒ 逆行 0.2576%（设计 0.203%）= 1.27×
另一笔  : entry 83508.0 → exit 83821.0 ⇒ 逆行 0.3748%            = 1.85×
```
⇒ 修它只能**减少损失**，不能创造边际。

## 第 4 步：为什么方向会错 —— 今晚几十次实测的同一结论

所有测过的信号，**毛边际都在 0.1 ~ 2 bp**（成本 4 bp）：

| 信号族 | 实测毛边际 | 出处 |
|---|---|---|
| 订单流方向（水平） | 0.07 ~ 0.6 bp | 项目 `orderflow_signal_feasibility_20261010.json` |
| 订单流突增（事件） | 0.099 ~ 0.432 bp | 本文作者实测 |
| 波动率分档（低/中/高 × 5 持有期） | 45 组合 **44 个为负** | 本文作者实测 |
| 爆发行情（5m 振幅>1%）反转 | BTC +10.8bp 但 t=1.43 · **去极值后 −6.6bp** | 本文作者实测 |
| 量能 × 主动买方向 | 随量能单调上升，**>9.3× 才达 +7.06bp** | 本文作者实测 |

**量能×方向是唯一越过成本的**：

而当根 15m 量能比 **3.21×** ⇒ **差一点，所以 s06 正确地没触发**。

## 第 5 步：为什么「波动」不产生边际（经济学）

```
· 波动放大的是收益的【方差】，而不是【均值】
· 在 5m ~ 30m 尺度上价格近似随机游走 ⇒ 毛收益 ≈ 0
· 「波动大」≠「方向可预测」
· 而成本是固定的 4bp ⇒ 波动不降低它在收益中的占比
```

**补充：波动确实影响一件重要的事 —— 成本效率**
```
仓位公式: notional × (stop_pct + 4bp) ≤ max_loss
  止损 0.20% ⇒ 手续费占风险预算 【16.67%】
  止损 1.00% ⇒ 3.85%
  止损 2.00% ⇒ 1.96%
⇒ 高波动（宽止损）时成本效率更好。但前提仍是【信号本身有边际】。
```

## 第 6 步：数据缺口是否是主因？

```
· volume 有全量（292,482 行）⇒ 「量」的分析不缺数据

   因为在有全量方向的 TRX 上，信号也只在极端量能时才够本。
```

## 最终答案

```
「有数据」 ≠ 「有信号」 ≠ 「有正期望信号」

今天：505 个信号（不是没有信号）
      但方向预测能力 ≈ 0 ⇒ 扣 4bp 后为负
      176 笔止损单中 66% 即使不止损也亏 ⇒ 不是止损的错

⇒ 要「把握波动」，瓶颈不在【入场信号的多少】，
  而在【信号的方向性边际必须 > 成本】。
  目前唯一越过成本的（量能≥9.3× + 主动买方向）正在按年衰减，
  且需要先修数据才能在 BTC/ETH 上验证。
```
