## 一之二、100× 杠杆与强平模型（2026-10-11 用户指令）

**用户指令**：「模拟开仓全部设置100倍杠杆」+「要有强平模型」。

### 口径 A（用户确认）

```
保证金    每仓 15% 权益 = 1,500（【不变】）
名义      1,500 × 100 = 150,000（= 权益的 15 倍）
两仓合计  300,000（= 权益的 30 倍）
手续费    主口径按【名义】计：单边 30 · 往返 60 = 保证金的 4% / 权益的 0.6%；taker 边界单边 75
盈亏平衡  0.10%（往返费率）—— 杠杆【不改变】它以
```

### 强平模型（用户确认为必需）

```
数量      quantity = margin * leverage / price
强平价    多头 liq = entry × (1 − 1/100) = entry × 0.99
          空头 liq = entry × (1 + 1/100) = entry × 1.01
逐根检查  多头 low[t] <= liq → 强平 ；
          空头 high[t] >= liq → 强平      ← 用 low/high，不是 close
结算      按 liq 价成交，保证金【全额损失】，exit_reason = "liquidation"
```

### ⚠️ 唯一例外条款

**强平是唯一允许用盘中 high/low 的通道。** 其余所有阈值离场仍严格按**已收盘 close** 判定 + next-open 成交。

**理由**：强平是交易所强制事件，触发价是确定的；「猜阈值单能否成交」则不是。两者性质不同。

**保守性提示**：真实强平成交价通常**等于或劣于**破产价。按 liq 价成交属**略乐观**，建议加 liq 滑点做敏感性检验。

### 风险量化

| 情形 | 后果 |
|---|---|
| 单仓强平 | **−15% 权益** |
| 两仓同时强平 | **−30% 权益** |
| 两仓同时逆向约 3.3% | **权益归零** |

**实测 BTC 5m 单根 \|位移\|**：中位 0.042% · 99分位 0.365% · 最大 1.162% → **单根触发强平罕见，但【持有期内的累计不利波动】会频繁触发。**

### 样本衔接

**现有 24 笔平仓是【杠杆 1】样本，与 100× 样本不可直接比较。** 建议换 strategy identity 而非原地改，避免两套口径混淆。

执行层采用后缀 **`_100x`** 创建新身份（例如 `s06_volume_climax_reversal_100x`）。旧 1× 账户和事件账保留供审计，策略实验室总览展示当前 11 个 `_100x` 账户。

### 硬性要求

**若执行层未实现强平，100× 的结果【不得采信】**，策略应保持停止或回退杠杆 1 —— 否则亏损可超保证金、权益可变负。

## 三、为什么这 10 项基础策略互不重复

| 对照 | 区分点 |
|---|---|
| **s01 vs s02** | s01 用**当日固定前 12 根的会话极值**；s02 用**前收 ± 波动率缩放的对称轨**。区间构造法不同。 |
| **s01/s02 vs s03** | 前两者**事件驱动**（突破才动）；s03 **状态驱动**（动量为正就持有），仓位按波动率倒数缩放。 |
| **s01/s02 vs s09** | 前两者在**突破瞬间追入**；s09 **等回踩**才进——入场时机机制不同。 |
| **s01/s02/s09 vs s05** | 前三者顺势；s05 **逆势**，触发条件是统计偏离。 |
| **s05 vs s06** | s05 只看**价格统计偏离**；s06 核心条件是**成交量极端**，价格位移仅作确认。 |
| **s06 vs s07** | s06 用**总量+价格位移**做**反转**；s07 用**主动买卖方向失衡**做**延续**。 |
| **s07 vs s08** | **不是换参数**——预期收益**符号相反**，同一触发下的一对相反假设，必有一方失败。 |
| **s04 vs 其余** | s04 是**唯一双腿策略**，收益来自相对强弱而非市场方向；其余 9 项都是单腿方向性。 |
| **s10 vs 其余** | s10 的自变量来自**另一个标的**（BTC 预测 ETH）；其余全部来自被交易标的自身。 |

**明确排除的「伪新策略」**：同一机制换周期、换窗口、加止盈止损、加过滤器、加 ML 打分。

## 三之二、两处必须固定的实现口径

### s07 的 `flow_imbal`（Codex 已固定）

```
mode    = recompute
formula = 2 * taker_buy_base / volume - 1
inputs  = quant.candles 存储字段（volume, extras.taker_buy_base）
          —— 不使用 extras.flow_imbal 存档值
hash    = 此口径必须进入 rule_hash；改读存档值即为不同实现，须换 variant 身份
```
**量化过滤**：`volume[t] >= 0.5 * median(volume, 60)[t-1]`（基准 `shift(1)` 后 `rolling`；100 根预热满足 60 根窗口）。

### s08 的 ATR（入场时冻结，不漂移）

```
atr 定义   = mean( true_range[entry-1-i], i=0..13 )  —— 取自【入场信号根之前的 14 根】
冻结       = 建仓后 atr 固定不漂移；止损/止盈阈值一经确定即不再随新 K 线变化
触发参照   = 已收盘 close（不是盘中 high/low 触及）
成交       = next-open 代理（t+1 根开盘）
跳空       = 若 t+1 开盘已越过阈值，按【实际开盘价】成交，绝不回填阈值价
明确不做   = 不模拟交易所盘内止损单；不把 K 线高低触及当作阈值价成交
```

**这条与 s02/TP-SL 规格里的 R-b 原则一致：跳空按实际 open，禁止按目标价回填 —— 否则会系统性高估收益。**

### s02 的中心参照（文本已统一）

```
mechanism 文本与 entry_formula 现已一致：【当前 open】为中心，不是前收
```

### s03 的仓位调整限制

```
size_multiplier = min(target_vol / rv, 1.0)   —— 上限 1，不加杠杆
```

## 五、全局规则（已冻结）

| 规则 | 内容 |
|---|---|
| **因果性** | 只用截至当根**已收盘**的数据。滚动基准必须 `shift(1)` 后再 `rolling`；**禁止全样本分位**。 |
| **成交模型** | 信号在 D 根收盘成立，成交在 **D+1 根开盘**。跳空按实际开盘价，**禁止回填目标价**。 |
| **成本** | 主口径 maker 0.02%/边；taker 0.05%/边作为保守边界。**限价单未成交风险、滑点与资金费记 unknown**；资金费可正可负，**0 不是上界**。 |
| **收益三分类** | 已平仓 / 浮盈 / 未成熟标签，**必须分开**；未成熟绝不进胜率与期望。 |
| **汇报义务** | 任何结论必须**同时给出毛优势与成本**。只报 IC / 胜率 / 夏普视同**未完成**。 |
| **禁止补造** | **禁止补造历史模拟成交。** 历史只用于实现正确性校验；收益结论必须来自前向记录。 |
| **资金** | 每个策略**独立账户 10,000 USDT**；账户间不得共享资金、订单或持仓。 |

## 七、评估条件（统一）

1. **先验可执行性**：策略能对每根 K 线无歧义给出决策
2. **确定性**：同一份数据重跑两次结果相同
3. **对照自检**：注入一个**应为负**的对照（如随机入场），它必须被判为负
4. **成本门槛**：**毛优势 > 往返成本**，且在**至少 2 个独立时间段**成立
5. **配对比较**：与同期同币的其它策略做配对，报告 `mean(diff)` / `t` / `σ_d` / 多重比较校正
6. **只有前 4 项通过**，才解读收益与排序
