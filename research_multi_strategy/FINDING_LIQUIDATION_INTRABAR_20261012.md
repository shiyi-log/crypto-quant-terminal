# 发现：项目的强平判定用「收盘口径」，低估真实强平频率 2.4 倍

> 2026-10-12 · DSH · 目标第 63 轮 · 属 **Q3（策略是否可上线）** 的直接输入

## 一句话

**真实交易所在盘中触及强平价时立即强平；项目只在收盘/下一根开盘越界时结算。**
在 100× 杠杆下，这个口径差异使项目显示的强平频率 **一致地偏低约 2.4 倍**（9 个组合 1.9~2.5×）。

---

## 1. 项目现状（代码证据）

```python
# strategy_simulation.py
def liquidate(pair, position, trigger_price, *, phase: str):
    liquidation_price = position["liquidation_price"]
    model = "open_bankruptcy_price" if phase == "next_open_ban[kruptcy]" ...
# EXECUTION_MODEL:
"open_bankruptcy_breach_policy": "bankruptcy_settlement_before_pending_exits_and_entries"
```

→ 强平在 **下一根开盘** 结算，**不是盘中触及即平**。

**100× 下的强平距离（项目公式 `liq = entry × (1 ∓ 1/leverage)`）**：

| 杠杆 | 多头强平价（entry=100） | 逆行距离 |
|---|---|---|
| 1× | 0.00 | 100% |
| 10× | 90.00 | 10% |
| 50× | 98.00 | 2% |
| **100×** | **99.00** | **1%** |

→ 项目现用 100×，因此 **1% 逆行即强平**。

## 3. 与项目实测的对照

```
项目实测: 1 次强平 / 155 次开仓 = 0.64%
项目口径（收盘）: 与 0.64% 量级相符 ✅
真实口径（盘中）: 应显著更高 → 【项目低估了真实强平频率】
```

## 4. 对 Q3「策略是否可上线」的含义

```
100× 杠杆的特征:
  · 强平距离仅 1%（项目公式）
  · 真实盘中强平频率 = 项目显示的 ~2.4 倍
  · 一次强平 = 亏光保证金（100× 下）

⚠️ 关键结论: 收盘确认的止损【挡不住盘中强平】
   止损在 1.5×ATR（15m 约 0.52%）且【收盘确认】；
   而强平在 1% 且【盘中触发】
   → 若某根 K 线盘中逆行 1.2% 但收盘只逆行 0.3%：
      真实：强平（亏光保证金）
      项目：不止损（收盘未越过 0.52% 止损）也不强平（收盘未越过 1%）
     ⇒ 【项目会漏掉这类真实爆仓】
```

## 5. 建议（属主会话域，我不改代码）

1. **强平判定改为盘中口径**：用 `low`（多头）/ `high`（空头）判断是否触及强平价，
   而不是用收盘/下一根开盘
   ⚠️ 需注意与「下一根开盘成交」的 fill_model 的一致性 —— 两者不能矛盾
2. **若保留收盘口径，必须在裁定规则里显式标注**：
   「本项目强平频率按收盘口径，约为真实盘中的 1/2.4」，
   并据此对「可上线」判断做保守修正
3. **补强平事件的数据完整性**：当前 `liquidation` payload **缺** `notional` /
   `entry_price` / `fees` / `net_pnl` / `gross_pnl`（而 `trade_closed` 有）
   → 无法审计那次强平扣了多少

## 6. 局限

- 强平距离按项目公式（`1/leverage`），未含维持保证金（0.5%）与逐仓细节；
  真实距离会因维持保证金而**更近**（→ 真实强平频率**更高**，方向不变）
- 未考虑资金费对强平价的影响
- 样本覆盖 2024-01→2026-10（TRX 全周期），含多个市场状态
