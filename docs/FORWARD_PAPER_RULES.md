# 前向纸面规则与执行口径

2026-10-10：把横盘过滤和止盈止损接入纸面执行层。这里只记录规则与实现证据，不代表已经获得收益改善。生产 `TrendFollowing`、运行配置和交易进程不受本次变更影响。

## 固定初始规则

默认变体全部使用 Donchian 20/20，共享币池、资金、top_n、槽位、敞口、手续费、成交时序和缺失数据规则。不扫描入场通道来增加样本。所有阈值是事前指定的研究假设，观察期内不调整。

| 类别 | 假设 | 初始规则 |
| --- | --- | --- |
| 基线 | 保留现状供对照 | 无横盘过滤，无额外 TP/SL |
| 横盘过滤 | 拒绝趋势/波动不足的候选 | ADX(14)>25；close 通道宽度(20)>0.5%；收益率波动率(20)>0.3%，各自独立变体 |
| 固定止盈 | 观察提前兑现的代价与收益 | 0.5%、1%、2%，各自独立变体 |
| 固定止损 | 观察提前截断亏损 | 0.3%、0.5%，各自独立变体 |
| 固定组合 | 同时约束兑现与亏损 | TP 1% / SL 0.5%，有/无 ADX 过滤 |
| ATR | 用入场时已知波动率设距离 | TP 2×ATR(14) / SL 1×ATR(14) |
| 移动退出 | 观察有利水位回撤退出 | trailing 1% / SL 0.5% |

共 13 个变体。`value=0.5` 表示 0.5%，ATR 的 `value` 表示倍数。移动退出是从冻结的有利价格水位回撤指定百分比，没有额外的盈利激活阈值，因此它可能在尚未盈利时触发；报告和前端将其称为“跟踪退出”，不把它解释成已锁定利润的止盈。`channel_width_pct` 是滚动 close 最大/最小值之差除以信号 close，再乘 100；`realized_vol_pct` 是滚动 close 收益率的样本标准差乘 100。

低于波动率阈值的示例没有用作默认“拒绝横盘”规则。用户可显式冻结 `op=lt` 的独立假设，但它的含义是选择低值，不能描述为排除低波动。没有使用全历史中位数或未来数据来求动态阈值。

## 时序与缺失数据

- 入场、过滤与入场 ATR 使用信号 K 线已完成的数据；指标窗口或 warmup 不足时拒绝入场。
- TP/SL 由已完成的 D 根 OHLC 判定，退出意图在 D+1 根首个有效 open 成交。反向突破退出采用相同成交时序。
- 同根触及 TP 和 SL 时按止损优先。移动止损先用上一根已知水位判当前根是否触发，再更新当前根水位，不猜测盘内路径。
- 无论开盘是否跳空，实际纸面成交价都是执行根 open，绝不把目标价回填为成交价。这是收盘触发、下根执行的模型，不能解释为交易所盘内保护单。
- 缺成交 open 时保留不可撤销的 pending exit、原原因和触发证据；退出成交后才释放资金和槽位。退出成交所在的开盘批次不复用该槽位，新入场从下一根执行开盘开始。
- 排名前 top_n 的币因过滤或缺数据被拒绝时不递补。信号数据不完整时不能缩小白名单后重新排名。
- 固定百分比距离以入场成交价为基准；ATR 距离使用入场信号时已冻结的 ATR。重启与断档恢复保留风险水平、移动水位及 pending 意图；观察缺口不能伪造缺口内成交。

## 可审计身份与展示

`rule_hash` 覆盖通道、过滤器全部字段、TP/SL 全部字段、百分数单位，以及 `dual_touch=stop_loss_first`、`gap_fill=execution_open`、`exit_timing=next_open`、`slot_release=after_exit_fill_next_open`。该槽位规则表示退出释放的容量从下一开盘起可用。执行源码指纹覆盖引擎与指标辅助模块。数据指纹保留 high/low；修改它们不能复用旧数据身份。

每个决策记录过滤原值、阈值、比较方向、指标是否就绪及拒绝原因。退出记录目标水平、触发 K 线和选择原因；成交记录实际执行 open。生命周期 ID 把决策、入场与退出关联起来。JSONL 是本地追加 outbox，PostgreSQL 保存幂等镜像，前端展示同步状态；数据库不可用不阻断本地纸面观察。

规则或执行源码改变后必须新建输出目录。旧 ledger 保留，不原地补写历史规则、分数或成交。`forward_paper_runner.py` 的 CLI 每次处理一份累计快照；持续观察需要调用方定时提供已完成 K 线，此次不自动启动服务。首份快照的历史只做指标热身，不产生历史订单。

## 结果解释与验证

已平仓手续费后收益、浮盈亏、未成熟结果独立呈现。手续费使用冻结的模型费率；滑点和资金费未知时 `net_profit` 保持空，不能声称完整净收益。纸面成交不混入 Freqtrade 的实际模拟订单。

合成数据验证包括长/短 TP/SL、同根双触发、执行根跳空、缺 open 挂起、过滤 warmup、无递补、ATR 冻结、移动水位与重启恢复、OHLC 指纹与哈希变化。未来价格扰动不得改变其尚不可得时的开仓或退出决定。通过这些检查只证明实现满足冻结规则。

收益比较先核对记录完整性与规则可执行性，再在事前固定日期观察手续费后收益与回撤。改变 TP/SL 也会改变持仓占槽位与后续入场，因此独立账户不是“同一批入场”的纯退出实验：配对报告只比较真正匹配的 `(coin, open_date, side)`，同时披露未匹配交易，不能忽略选样差异。单独锁定同源入场的退出影子实验仍需另建账本。
