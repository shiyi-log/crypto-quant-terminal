## 代际结论

- 自动第 20 轮为一个配置 trial、三个种子，与早期单种子记录不是严格同口径。超参数相同不能推出权重、数据或评估口径相同。
- 当前 `TrendFollowing` 没有消费 ML 模型产物的路径。现有证据不能把任何 ML 轮次的变化归因为实际订单或收益改善。
- 作废历史指标与撤回原因保留，不再作为策略可用性或晋升依据。完整代际审计在 `artifacts/generation_audit_20261010.json`，盘口审计在 `artifacts/orderflow_audit_20261010.json`。
- 含前视的旧引擎、未净化成熟期的训练切分、整段池化排名和不可比的种子对照不能用来下生产结论。相关旧命令入口保留源码并禁用，避免再次复用。

## 记录与查询

在项目根目录使用已经配置的 PostgreSQL 连接，显式同步本机记录：

```text
uv run python research_ledger.py --sync
```

事件按内容幂等追加；修订以新事件表达。模型原始注册表与试验记录留在本机，API 的订单来源固定为 `bot/tradesv3.dryrun.sqlite` 的数据库镜像。`/api/locals/research-ledger` 需要登录，只查询，不执行同步、训练或交易。

业务订单当前来自 Freqtrade 模拟盘；它们是实际发生的模拟订单，不是实盘成交。纸面回放的代理成交另存，不能混入业务收益。浮盈、已平仓收益与未成熟标签分开；滑点及资金费未知时不能宣称完整净收益。

本次已实际同步 23 个登记版本、450 条试验事件、2 条教训、4 个方向、2 份审计。投影去重后显示 248 条版本/试验、8 笔模拟交易及订单、0 笔平仓、0 个已验证部署的 ML 模型；已实现收益保持未知。账本 API 实际 HTTP 200 与浏览器页面均已核验。仅更新认证、前端与实时图表服务，Freqtrade PID `39412` 未重启。

最终验证：后端 253 项全部通过（独立 PostgreSQL 集成实际执行），桥接 101 项通过、2 项真实模型联网测试未执行；前端类型检查与生产构建通过。具体命令与边界见 `artifacts/verification-20261010.txt`。Ruff 为明确列出的有效路径检查；封存的历史源码保留旧静态问题，不宣称全仓 lint 通过。

| 收益目标 | 成本完整性、已平仓收益/回撤/敞口、同口径无模型影子基线 | 无可信的前向增量结论，不追加历史搜索来代替观察 |
| 持续多变体干跑 | 一个实时数据源、冻结规则、独立账户状态、重启恢复、数据库/页面对比 | 当前只有离线 runner；尚未启动多变体前向服务 |
