# Demo 三问题证据与启动

目标是用 Binance Demo Trading 的实际成交和同信号纸面对照，检查费用、策略净损益和执行机制。仅使用 BTC/ETH/TRX，不连接 Testnet 或实盘。页面位于 `http://127.0.0.1:8888/#/quant/binance-demo`。

## 当前启动条件

适配器、签名端点检查、持久化订单意图、实际成交入库、撤单和单策略镜像链路已实现。部署核对时尚无 Demo 凭据、订单或成交；集成测试通过不代表已经连接过真实 Demo。

用户在 [币安 Demo API 管理](https://demo.binance.com/en/my/settings/api-management) 创建独立 Demo API key/secret，在本机前端保存。服务端加密保存数据库，主密钥独立保存；接口不回传密钥。不要使用实盘密钥，也不要发到聊天或提交仓库。

保存后先点击“检查连接”：该动作只读 Demo 余额、仓位，以及 BTC/ETH/TRX 的账户报价费率。检查通常在数秒内返回，网络或限频可能延长。选定一个已冻结的单腿 ATR 账户并手动启动后，才允许 Demo 合约交易；因此只读 API 权限不能完成执行验证，需要独立 Demo USDⓈ-M 合约交易权限。首笔订单和成交时间取决于未来信号、门控与撮合，不能保证立即发生。

## 证据口径

1. **费用**：签名 `/fapi/v1/commissionRate` 返回账户报价 `makerCommissionRate/takerCommissionRate`，保存来源与观察时间。实际扣费来自 `demo_fills` 的原生 `commission/commissionAsset/isMaker`，按币对、maker/taker、入口/退出分层。有效费率使用实际 USDT commission 除以原回报 `quoteQty`；缺字段、冲突、非 USDT 未换算时保留未知。实际费率可以恰好等于先前假设值。
2. **净损益**：完整实际往返采用回报 `realizedPnl` 减实际手续费；成交价格已经反映执行结果，不再次扣信号价偏差。尚未采集资金费，因此该指标不含资金费。现有 runner 镜像分钟/小时 K 线策略；五秒轮询、三十秒挂单期限或偶然短持仓不能充当秒级策略实验。Q2 状态保持 `seconds_experiment_not_configured`，需独立冻结秒级规则和同信号对照后再评估。
3. **执行**：全量证据报告的未成交主分母仅包含有交易所订单号的已接受、已终结入口；分子为其中零成交的订单。交易所明确拒单、本地过期/未确认、待处理/未知订单和部分成交另计。旧 runner/Store 的“尝试提交后终结入口”统计是另一人口，不应混用。意图、撤单、过期和实际回报均保留，原生 Binance camelCase 字段可查。

同一冻结纸面策略的身份、输入和 Demo 政策进入对照记录；Demo 名义上限与实际保证金条件可能和纸面不同，因此对照首先衡量信号执行差异，不能直接归因整个组合收益。

`GET /api/locals/binance-demo/evidence` 使用全历史账本和 `REPEATABLE READ READ ONLY` 一致快照，不读取凭据，不连接交易所，不初始化或迁移数据库，不受页面记录窗口限制。重复成交、身份/政策错配或不能对账时拒绝生成误导性结论。

## 结论限制

币安官方说明 Demo 图表、订单簿定价和执行可能与实盘不同，Demo 表现不是未来实盘收益的可靠指标。Demo 未成交率只证明 Demo 的机制。成交相对实盘纸面信号收盘价的偏差同时包含环境差异与时延，不是实盘滑点；静态盘口走档是即时冲击估算，不替代真实成交。

已报告的短窗 OBI 测算只能约束对应资产、信号和窗口，不能否定所有秒级策略。没有实际成交时，费用、净额、未成交率均保持待证据。上线始终需要人工审查，不自动启用实盘。

独立核对见 [OBI 报告效力范围](Q2_OBI_EVIDENCE_REVIEW_20261012.md) 与 [强平模型核对](LIQUIDATION_MODEL_REVIEW_20261012.md)。当前纸面实现已按 low/high 检查盘中强平，但仍使用破产价代理，不能等同真实标记价与维持保证金风险；Demo 不自动设置纸面 100 倍杠杆。
