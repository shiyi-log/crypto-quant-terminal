## 因子事实与展示状态

因子观察表显示源 factor、group、ic_base、ic_recent、t_recent 与 alert，检查器保留 drift、status、weak、flip、decay。真实零显示为零；缺失统计值与标记显示未知。字符串统计值保留来源精度，不把未知值补成零或正常。

解析器要求 factors 是真实数组、每行有唯一非空因子身份、统计值为有限数值或合法数值文本、标记为布尔值。损坏或缺少列表会拒绝整份响应；成功空数组单独呈现，并说明旧监控快速模式也可能省略因子计算。

旧监控 generated_at 明确为北京时间无时区文本，页面按 +08:00 解释；带明确时区的 ISO 文本亦可读取。无效日历、未知或未来时间不显示新鲜。一小时仅是页面上的历史监控时效规则，与信号成熟和交易资格无关。失败刷新保留上次成功快照，同时展示读取错误与快照时效；首次失败不会声称已有旧快照。

该接口没有 factor_versions、输入指纹、逐币逐周期时序 IC、相关性、市场阶段、消融、bootstrap/HAC、全实验族校正或最终留出状态。检查器持续显示缺口与“不授予 Demo 准入”。

## 请求生命周期

因子读取器为每次读取创建 AbortController 和递增请求身份。重新读取或卸载后，旧响应、旧异常和旧 loading 收尾均不得覆盖当前状态。当前 getOps 兼容 API 没有信号参数，因此取消用于阻止迟到发布；不声称已取消底层 HTTP。错误文案固定，不把请求异常中的地址或敏感参数原样渲染。

因子只在进入与手工刷新时读取；30 秒计时器只更新快照年龄，不轮询网络。实验列表与选中运行使用独立请求身份，防止运行 A 的详情晚到后显示在运行 B 的检查器中。

## 实验运行与证据

实验运行账读取最多 100 条实际返回记录，同时展示返回条数与源 total，不把当前页当作完整实验族。执行状态与旧研究裁定分列；失败轮次和不可评估轮次保留。合法的 strategy、model、timerange 空字段按未知显示；缺少 items、total、重复 run_id 或损坏的嵌套合同会拒绝发布。未知状态使用固定未知文本，不从对象原型属性取值。

选中运行同步到 run_id 查询参数，进入深链接时直接读取指定轮次，即使该轮不在当前列表中也不会回退到最新结果。多值或空 run_id 显示身份无效；详情返回身份不匹配时拒绝发布。选择另一轮清除前一轮详情，同轮刷新失败保留该轮上次成功事实。

统计按 entry.metrics、metrics、gate.values 的顺序合并，后端规范判据优先，明确的 null 继续为未知。数值文本保留精度且要求有限值。页面明确说明完整费用、资金费、滑点和压力场景尚未核对，不把源收益指标更名为完整成本后净收益。代码、数据、策略、执行、成本、风险指纹只显示实际返回值，缺少时显示未知。

实验族数据库预注册、120 配置上限、固定种子、全族校正、最终留出单次状态与新准入裁定均未接通。旧产物页尚不读取指定 identifier，因此生产页面只提供明确的历史列表与手动选择入口，不宣称已定位当前轮产物。

## 视觉与可访问性

页面使用计划固定的深蓝底色 #0C1B2A、工作面 #132B3E、边线 #29485C、正文 #E5EDF4、次级文字 #A2B8C9 和强调色 #69B4E4。字体采用 IBM Plex Sans、思源黑体与本地后备字体，不新增离线不可用的字体请求。

因子采用研究表格加证据检查器，实验采用运行账与运行详情。表格具有内部滚动容器，grid 子项 min-width:0；窄屏改为单列。按钮、筛选、链接与表格滚动区域提供可见键盘焦点，原生控件保留键盘操作。
