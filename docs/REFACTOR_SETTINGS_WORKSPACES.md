## 页面与事实边界

| 路径 | 新结构 | 保留的功能 |
| --- | --- | --- |
| `/quant/binance-demo` | 环境与身份带、四个设置分区、连接检查器、会话账本、执行记录 | Demo 凭据保存与只读检查，主策略选择／开始／暂停／切换，暂停并行绑定，独立会话开始／暂停／历史恢复，历史记录筛选，订单、成交、共享持仓／余额、对照、费用与净交易损益 |
| `/quant/pairlist` | 名单视图、主账簿、事实侧栏、冻结标的确认层 | 运行白名单，黑名单输入／批量移除、通配展开、名单方法和逐项错误，保护锁查询与解除，30 秒只读刷新 |
| `/quant/security` | 当前登录身份侧栏、修改密码、本机恢复 | 真实密码变更，当前已知用户名的本机随机密码恢复 |
| `/profile` | 基本信息、安全能力、密码三个分区 | 真实用户名、姓名、角色、说明，以及真实密码修改 |

Demo 设置与旧 Freqtrade 名单分开。旧锁解除不重设新账户风险锁；登录身份不代表
交易账户所有权。Demo 的并行研究会话不合并为正式验收收益。正式轮次仍需
独占账户、冻结身份、原生保护、完整成本和人工批准。实盘凭据入口保持未接通。

没有移除上述已有真实功能。退役的只是旧硬编码 admin 恢复命令、密码 toast、
完整密钥回显和重复的密码表单实现。密码修改及本机恢复由同一个工作台管理，
个人中心复用修改部分。已有手机、邮箱、MFA 无后端能力的事实说明保留。

## 读取、过期与身份

Demo 设置页通过专属 `settingsApi.ts` 直接校验原始响应，避免共享兼容读取器把
缺失 `items` 变成空列表。环境和端点必须是官方 Demo，列表坏行、错误布尔、
重复或缺失会话身份、缺失账户对象均进入未知或失败。账户、持仓和证据端点
不发送其不支持的 limit 参数。金额字符串保留原始精度。

整组读取前后核对凭据指纹、主会话、策略和冻结 hash。旧请求通过
AbortController 与递增序号失效，离页后不再写回。失败时只保留完全同范围的
旧值；范围由环境、端点、凭据身份、会话与策略 hash 共同决定。跨凭据或会话失败
清为未知，不能把旧订单挂在新身份下。相关记录、会话或证据读取失败时，新增风险
操作禁用；暂停入口保留。页面读取时间与交易所事实精确时点分开。

旧引擎白名单、黑名单、锁三来源独立保留数据、接收时间和错误。损坏响应不显示为空。
写命令需要对应来源在 60 秒内成功读取；保护锁 `reason=null` 按真实接口接受。
解除锁回执必须满足真实 `{lock_count, locks}` 合同，缺失结构视为未知。

## 命令与敏感信息

| 操作 | 请求语义 | 页面结果 |
| --- | --- | --- |
| 保存 Demo 凭据 | 用户确认后 POST，单项在途 | 输入在成功或失败后清空，不在 URL／存储中保留 |
| 只读连接检查 | 由用户触发已有 check 命令 | 只说明连通检查，不标风险与验收通过 |
| 开始／暂停／切换会话 | 用户操作和后端门禁共同决定 | 命令返回与会话／交易所事实分开核对 |
| 黑名单或锁命令 | 确认层冻结标的，重复确认去重 | 合法回执、逐项拒绝、未知与后续 GET 事实分开 |
| 修改密码 | 验证当前密码、新密码、确认值和当前身份 | 成功清空输入及旧本地会话，重新登录；失败无假成功 |
| 本机恢复 | 只为当前已知用户生成随机密码 | 返回需用户名一致、generated=true 和有效密码；结果仅驻留当前页面 |

所有页面进入只发读取，不自动发送上述命令。未知提交不自动重试。
Demo 风险、归属冲突、策略拒绝和异常只显示固定中文说明，未知上游文本不回显。
本机恢复密码默认遮蔽，用户可显示、复制和清除；离页销毁。密码不进入 toast、
日志、URL 或浏览器存储。身份变化后的旧成功和失败都被丢弃。
